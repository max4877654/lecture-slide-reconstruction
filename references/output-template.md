# 讲解还原稿输出模板

## 整体结构

讲解还原稿按以下顺序组织：

1. **课程全局概览**（一节课一段）
2. **逐页解读**（每页一节，重点页详写、过渡页简写）
3. **待核验清单**（有 `⚠️ 待核验` 项时必给，可直接粘贴给 glossary-verifier 会话）
4. **全局逻辑链总结**（可选，用户要求时给出）

## 全局概览写法

用 3–8 个阶段概括全课主线，每个阶段一句话：

> **本课主线**：现象引入（P1–P3）→ 核心概念定义（P4–P6）→ 机制/原理剖析（P7–P10）→ 代码实现演示（P11–P13）→ 工程权衡与常见错误（P14–P16）→ 总结与下节预告（P17）。

随后列出 2–4 个"本课关键问题"，即 professor 整节课试图让学生回答的问题。

## 逐页解读模板

每页输出格式如下（用 markdown 二级标题分页）：

```markdown
## 第 N 页：<slide 标题或自拟一句话概括>

**页面功能**：引入 / 铺垫 / 核心论证 / 举例 / 对比 / 总结 / 过渡（选一个或多个）

**版面解读**：
- 视觉锚点是 <元素>，professor 希望学生先看 <X> 再看 <Y>。
- 图文空间关系：<图片是文字的例证/对照/前提；文字是对图的标注/推导/结论>。

**核心信息**：
- 显性内容：<slide 上写了什么>
- 隐性叙事：<professor 为什么此刻展示这页；slide 上简略但会口头展开的点>

**与前文的衔接**：<如何从前一页推进；前一页留下了什么问题，本页如何回应>
**为后文的作用**：<为哪一页埋伏笔 / 提供什么前提>

**[可选] ⚠️ 待核验**：<术语/框图名>——<为何存疑，一句话>
**[可选] ⚠️ 陌生代码段**：见下方代码块模板
**[可选] 📊 重要图表**：见下方图表块模板
```

教学功能定义（供"页面功能"选择）：

| 功能 | 含义 |
|---|---|
| 引入 | 制造问题或现象，打开认知缺口 |
| 铺垫 | 提供后续内容必需的前置概念 |
| 核心论证 | 本课的关键推导或核心观点 |
| 举例 | 用具体实例巩固抽象概念 |
| 对比 | 新旧方案/正误做法对照 |
| 总结 | 收束前面内容，提炼要点 |
| 过渡 | 话题切换的桥接页，常含下节预告 |

## 代码块模板

```markdown
**⚠️ 陌生代码段**（或 **代码示例**）
- 语言/环境：<语言>，运行于 <环境>
- 功能概述：<一句话>
- 关键行解释：
  - `<关键行>`：<作用、为什么这样写>
- 课堂角色：<概念例证 / 反面教材 / 作业模板 / 工程示范>
- professor 可能的口头补充：<推断，注明依据>
- [可选] ⚠️ 待核验：<涉及的 API/库/工具链及版本>
```

## 图表块模板

```markdown
**📊 重要图表：<图的名称/类型>**
- 图是什么：<类型；坐标轴/各部分含义>
- 展示结论：<一句话>
- 放在此处的意义：<验证上页理论？预示下页问题？制造认知冲突？>
- 读图要点（professor 会强调的细节）：
  1. <细节 1 及其意义>
  2. <细节 2 及其意义>
- [可选] ⚠️ 待核验：<数据性结论/反直觉声称>
```

引用术语表时的格式：`（glossary：高置信度，一致）` 或 `（glossary：低置信度，⚠️ 存疑）`。

## 待核验清单模板

```markdown
## 待核验清单（供 glossary-verifier 会话使用）

| 术语/框图名 | 课件出处 | 课件中的表述（原文摘录） | 存疑原因 | 建议核验方向 |
|---|---|---|---|---|
| <名称> | 第 N 页 | <原文> | <课程特定命名？/非标准缩写？/有争议归类？> | <教材/标准/论文/官方文档> |
```

规则：

- 课件出处必须精确到页；"课件中的表述"必须是原文摘录，禁止转述。
- 本清单可直接整段粘贴到 glossary-verifier 会话作为核验输入。

## 还原质量自检清单

输出前逐项检查：

- [ ] 是否覆盖了全部 slides（或说明哪些页被有意简写及原因）？
- [ ] 每页是否都回答了"professor 为什么此刻展示这一页"？
- [ ] 图文空间关系是否被显式分析，而非只描述"有一张图"？
- [ ] slides 之间的逻辑链是否成文，关键转折点是否标注？
- [ ] 所有陌生代码段是否按模板单独解释（语言、环境、功能）？
- [ ] 所有重要图表是否按模板单独解释并联系了前后文？
- [ ] 所有推测性内容是否明确标注为推断并给出依据？
- [ ] 是否存在 slide 上完全没有根据的臆造？如有，删除或改写为带依据的推测。
- [ ] 所有待核验对象是否都已标注 `⚠️ 待核验`，且未在分析过程中自行联网搜索？
- [ ] 若引用了 glossary.md：是否注明了出处与置信度？课件表述与表内记录冲突时是否显式呈现而非静默选边？
